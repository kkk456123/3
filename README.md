## 本地运行

建议使用 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

开发服务器默认地址为 `http://localhost:5173/`。生产构建和本地预览：

```bash
npm run build
npm run preview
```

项目不需要后端服务。联系按钮使用 `mailto:`、`tel:` 和站酷外链。

已完成视频、图片、WebGL、滚动监听、GSAP 与首屏加载优化，详见 [PERFORMANCE.md](./PERFORMANCE.md)。首页使用轻量背景视频和 480px 作品缩略图；详情页保留原始视频画质，图片通过 srcset 选择合适尺寸。旧资源备份位于 `source-assets/archive-public/`，不参与部署。

电脑端各主模块使用至少一屏的布局节奏（`min-height:100svh`），内容居中，上下留白随屏幕高度调整；内容本身超出一屏时自然延长，保证完整展示。联系方式为整屏收尾，主内容居中、页脚位于底部。手机端按内容自然排布，联系卡片与页脚之间保留 48px 间距。

## 部署到 GitHub Pages

项目已包含 `.github/workflows/deploy.yml`。将项目根目录中的所有文件推送到 GitHub 仓库的 `main` 分支后，工作流会自动安装依赖、构建并发布 `dist/`。Vite 会根据仓库名自动设置 Pages 子路径，也支持名为 `用户名.github.io` 的用户站点。

首次部署步骤：

1. 在 GitHub 创建一个仓库，建议使用公开仓库，并将本项目根目录的所有文件上传到仓库根目录。请保留 `.github/workflows/deploy.yml`。
2. 打开仓库的 **Settings → Pages**，将 **Build and deployment → Source** 设为 **GitHub Actions**。
3. 推送到 `main` 分支，或在仓库的 **Actions** 页面手动运行 **Deploy to GitHub Pages** 工作流。
4. 工作流成功后，在 **Settings → Pages** 查看访问地址。项目仓库通常为 `https://用户名.github.io/仓库名/`；用户站点仓库通常为 `https://用户名.github.io/`。

后续每次推送到 `main` 都会自动重新部署。若默认分支不是 `main`，请同步修改 `.github/workflows/deploy.yml` 中的触发分支。

作品带支持方向键、Home、End、Enter，键盘聚焦时暂停并将当前卡片移入视野。触屏可横向拖动，同时保留纵向页面滚动。离开视口、页面隐藏、开场期间和系统启用“减少动态效果”时停止自动帧循环；减少动态效果模式下仍支持手动拖拽与键盘浏览。

USAMS 详情页使用提供的 `作品集网站/USAMS排版.jpg`，原图为 1920×28935。已按原始作品的黑色分隔线裁成 54 张完整画面，资源位于 `public/assets/project-panels/usams/`，不再按固定高度截断同一张作品。桌面保留全宽、双列、三列及中部双列错落布局；手机统一单列。完整原始 JPG 保存在 `source-assets/usams-layout.jpg` 中。

首屏视频保留原有 40% 黑色遮罩，再叠加一层 40% 黑色遮罩（两层合成约 64% 黑色遮挡），并保留杂色层；47px 高度的圆角导航固定悬浮于顶部，进入下方内容后增强磨砂玻璃效果。下方依次为个人资料与星球光晕工作经历、拼贴式视觉作品、五张个人优势卡片，以及全屏联系方式。所有按钮与链接均有颜色过渡的悬浮反馈。

## Grainient 背景

根据用户提供的 React Bits Grainient 组件代码集成，使用原生 WebGL2，无额外运行依赖。背景由个人经历、视觉作品、个人优势、联系方式四个模块共用，首屏视频独立展示。颜色为 `#000000 → #103554 → #000000`，使用径向渐变、丝绸光泽与轻微杂色；主要参数在 `src/App.jsx` 的 `<Grainient />` 中。

## Crosshair 光标交互

根据提供的 React Bits Crosshair 源码集成，组件为 `src/components/Crosshair.jsx`、`Crosshair.css`，配置在 `src/App.jsx` 的 `PortfolioCrosshair` 中。使用 Canvas 2D，无新增依赖。全屏十字线为网站主色 `#d4ff47`，线宽 0.75px、透明度 0.48、边缘渐隐 0.85、跟随平滑度 0.35，交点留出 9px 空隙。保留坐标提示、交互目标四角锁定框及点击扩散圆环，同时保留系统鼠标光标与作品带抓取手势。导航、按钮、作品卡片、头像、个人优势及视频滑块均可触发锁定；视频画面的整块播放区域不显示锁定框。

作品弹窗在浏览器顶层中使用独立 Canvas，打开时暂停底层效果，关闭后恢复。Canvas 不接收鼠标事件，不影响作品点击、拖拽、滚动及视频操作；视频全屏时隐藏光标装饰。触屏输入不触发效果，纯触屏设备自动隐藏。运行时切换“减少动态效果”会移除平滑跟随延迟、锁定过渡和点击圆环。Canvas 像素比最多为 2，静止且过渡完成时停止帧循环，页面隐藏、组件卸载时取消绘制并清理监听器。

背景只有一张视口大小的画布，首屏后开始流动，回到首屏时暂停。开启系统“减少动态效果”时，渐变背景停止动画；浏览器不支持 WebGL2 时自动显示静态 CSS 渐变。背景不拦截按钮、作品卡片和导航的点击。

首屏视频按“黑色耳机（video/hero-black.mp4）→ 白色耳机（video/hero-white.mp4）→ 黑色耳机”的顺序循环，使用独立轻量背景版本。播放列表在 `src/data.js` 的 `heroVideos` 中，素材均位于 `public/assets/`，无需依赖原始磁盘路径。站酷链接统一为 https://www.zcool.com.cn/u/ZNTk4OTg0ODA= 。

## 开场与滚动动效

三个英文模块标题、个人介绍「Hi, I am Harvey!」与联系方式中文大标题使用独立字符悬停层：鼠标经过单个字或字母时，平滑放大至 1.16 倍并切换为主色 `#d4ff47`，移开恢复；通过 transform 放大，不挤动相邻文字。字符层与 GSAP 的词/行进场层分离，遮罩留有放大空间，整句通过标题 aria-label 保持可访问名称。纯触屏不触发悬停；减少动态效果时直接切换状态。导航和联系方式区域的 Harvey 标识均链接到 `#top`，页脚「回到顶部」改为 56px 高的磨砂圆角按钮，带淡绿色圆形上箭头，手机端高度 48px。

使用随项目安装的 GSAP + ScrollTrigger，无需 CDN。代码集中在 `src/motion/usePortfolioMotion.js`，遮罩、独立位移层和图片层样式位于 `src/motion/motion.css`。

首屏开场约 3.35 秒：深色幕布从中间上下揭开，视频画面由收窄的窗口展开；HARVEY 逐字上推、压缩展开归位，PORTFOLIO 遮罩揭开；导航、介绍、星形装饰和底部作品带按节奏接续出现。用户在开场期间直接滚动或使用键盘导航时，会立即完成开场，让出操作。通过 #about、#projects 等锚点打开页面时跳过开场。

滚动时，模块英文标题先做遮罩揭幕、大幅位移与横向展开；卡片随后按约 0.17 秒的间隔依次入场。卡片位移约 112px，手机端收至 64px，动画持续约 1.55 秒；头像和作品图另有约 1.7 秒的图片揭幕。工作经历标题、星球弧面与联系方式大标题也有各自的进场编排。页面保持原生滚动，模块进场只播放一次，回看时内容直接展示。

桌面端的四张作品图片有小幅滚动视差，使用内层图片位移，外层保留圆角裁切；原有图片悬停放大、卡片边缘光和优势卡片绿色反馈独立运行。手机端关闭视差。位移、缩放与透明度动画不改变布局，图片揭幕只在入场时运行；卡片动画结束后移除临时 will-change。没有添加滚动劫持、固定整屏滚动场景或弹跳缓动。

开启系统“减少动态效果”后，开场、入场和视差全部停用，内容直接完整显示，视频和作品带按原有逻辑暂停。运行中修改此偏好也会撤销已有动画。React Strict Mode、断点切换和组件卸载时，会清理对应时间线、ScrollTrigger 与监听器。

作品详情中的第一段视频按项目要求在打开后自动播放，即使系统开启“减少动态效果”也保留这一行为；首页背景视频仍遵循上述偏好。
